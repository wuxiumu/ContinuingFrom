# PlayScout 海外游戏攻略站项目计划

## 项目定位

PlayScout 是面向英语用户的“游戏搜索答案站”，重点解决玩家正在搜索的具体问题：兑换码、免费物品、地图、种子、活动奖励和常见操作。首批覆盖 Roblox、Minecraft、Fortnite 与 Stumble Guys。

## MVP 范围

- 英文品牌首页与移动端布局
- 游戏、攻略、兑换码和地图四类内容入口
- 可复用的游戏卡片与攻略卡片
- 搜索入口及热门关键词入口
- 基础 SEO 标题、描述和语义化页面结构
- 本地开发与生产构建流程

## 内容矩阵

1. Roblox：Codes、Free Items、Games、Obbies、Updates、FAQ
2. Minecraft：Seeds、Mods、Skins、Maps、Commands、FAQ
3. Fortnite：Creative Maps、Skins、Codes、Events、Battle Pass、FAQ
4. Stumble Guys：Maps、Skins、Codes、Events、FAQ

## 30 天推进建议

- 第 1 周：确定品牌、信息架构、内容模型和 100 个首发关键词
- 第 2 周：完成列表页、详情页模板、站内搜索与结构化数据
- 第 3 周：发布首批 60–100 篇人工复核内容，建立更新节奏
- 第 4 周：接入分析与站长工具，观察收录、点击率与长尾排名

## 内容质量规则

- 兑换码必须标注最后验证时间并及时下架失效码
- 操作攻略先给结论，再给步骤，避免无效铺垫
- 版本相关内容必须明确平台、游戏版本与更新时间
- 每篇文章提供相关攻略、FAQ 与所属游戏的内部链接
- 不虚构奖励、兑换码、更新日期或官方来源

## 下一阶段功能

- 攻略详情页模板与 FAQ Schema
- 内容数据源与管理后台
- 搜索、筛选、标签及相关文章推荐
- Sitemap、RSS、Analytics 与 Search Console
